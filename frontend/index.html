Agent Pioneer Badge

A free badge for early Agent ID holders.

  • Free — you pay only the network gas fee.
  • 1 per Agent ID holder — one badge per wallet that holds an Agent ID.
  • Max supply: 1,000 badges, first come first served.
  • Network: BNB Chain.
Connect your wallet to begin.
How to connect:
  1. In the Binance app, switch to the Wallet tab (the Web3 Wallet) — the exchange app's own browser does not connect a wallet to pages.
  2. From the Wallet tab, open Discover and open this page's link in its dApp browser.
  3. Tap Connect Wallet and approve the connection in the app.
  4. Tap Check my Agent ID, then Claim Badge.

There is no QR code or pairing code login — the wallet connects only when this page is opened inside the Web3 Wallet's dApp browser.

This badge is a collectible with no monetary value and no promised returns. Live on BNB Chain — contract 0x6FBBe75e2111f8216737f5cf07D35b4F2474db95 (BscScan).
